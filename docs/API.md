# API reference

Interactive documentation is generated by FastAPI at `/docs` (Swagger UI), `/redoc`, and
`/openapi.json`. All request bodies are validated; invalid input returns `422` with details.

## Calculation

| Method | Path | Body | Returns |
|---|---|---|---|
| POST | `/api/calculate/full` | `ProjectInputs` | Full result: modules, capacity balance, warnings, power flow, Sankey, summary |
| POST | `/api/calculate/it-load` | `{ it }` | Tool response |
| POST | `/api/calculate/power-factor` | `{ kw \| kva, power_factor }` | kW ↔ kVA |
| POST | `/api/calculate/convert` | `{ conversion, value, voltage?, phase?, power_factor? }` | Unit conversion |
| POST | `/api/calculate/cooling` | `{ it_kw, rack_count }` | Heat load, tons, class |
| POST | `/api/calculate/circuit` | `{ voltage, current, phase, continuous_derate, rack_kw, power_factor, circuits_per_rack, receptacle_id }` | Circuit capacity & count |
| POST | `/api/calculate/pdu` | `{ rack_kw, power_factor, pdu }` | PDU sizing |
| POST | `/api/calculate/ups` | `{ load_kw, power_factor, ups }` | UPS (+ battery) |
| POST | `/api/calculate/transformer` | `{ required_kw, power_factor, transformer }` | Loading, FLA, fault current |
| POST | `/api/calculate/generator` | `{ load_kw, derate_factor, generator }` | Generator sizing |
| POST | `/api/calculate/bess` | `{ power_mw, bess }` | BESS sizing |
| POST | `/api/calculate/rack-density` | `{ rack_count, kw_per_rack, room_area?, … }` | Density, circuits, classes |
| POST | `/api/calculate/rack-count` | `{ it_kw, rack_power_kw, racks_planned? }` | Inverse rack count |
| POST | `/api/calculate/ai-rack` | `{ rack_count, rack_power_kw, pue, electrical, pdu, ups, … }` | Full result for an AI cluster |

Tool response shape:

```json
{
  "engine_version": "1.0.0",
  "modules": {
    "cooling": {
      "module": "cooling",
      "steps": [
        { "key": "btu_hr", "label": "IT heat load", "value": 204728.52, "unit": "BTU/hr",
          "formula": "BTU/hr = kW × 3412.142", "substitution": "60 × 3412.142",
          "assumption": "", "reference": "physics-conversion" }
      ],
      "data": { "classification": { "id": "containment", "name": "Air cooling with containment" } }
    }
  },
  "warnings": [
    { "severity": "caution", "code": "LIQUID_COOLING_REQUIRED", "title": "…", "message": "…",
      "affected_system": "cooling", "reference": "" }
  ]
}
```

Example:

```bash
curl -X POST http://localhost:8000/api/calculate/cooling -H "Content-Type: application/json" -d "{\"it_kw\": 60, \"rack_count\": 10}"
```

## Constants

| GET | Returns |
|---|---|
| `/api/constants/receptacles` | Receptacle library with derived nominal / usable kVA |
| `/api/constants/cooling-classes` | Cooling-density bands and thermal tiers |
| `/api/constants/voltage-levels` | 34.5 kV … 208 V |
| `/api/constants/presets` | Deployment presets (complete `ProjectInputs`) |
| `/api/constants/references` | `references.json` |
| `/api/constants/ai-racks` | AI rack classes and equipment references |
| `/api/constants/conversions` | Available unit conversions |
| `/api/constants/thresholds` | Warning thresholds |
| `/api/constants/environment` | Planning temperature envelopes |
| `/api/meta` | App name, engine version, disclaimer |
| `/api/health` | Liveness |

## Projects

| Method | Path | Notes |
|---|---|---|
| GET | `/api/projects` | List (summary) |
| POST | `/api/projects` | `{ name, inputs }` — results recomputed server-side |
| GET | `/api/projects/{id}` | Includes inputs, results, warnings, `calculator_version` |
| PUT | `/api/projects/{id}` | `{ name?, inputs? }` |
| POST | `/api/projects/{id}/clone` | Copy |
| POST | `/api/projects/{id}/recalculate` | Re-run on the current engine version |
| DELETE | `/api/projects/{id}` | 204 |

## Exports

All take `{ project_name, inputs }` and recalculate server-side.

| POST | Returns |
|---|---|
| `/api/export/pdf` | PDF engineering report |
| `/api/export/xlsx` | Workbook: Inputs, Results, Device Load List, Rack Summary, Capacity Balance, Warnings, Calculations |
| `/api/export/csv/{sheet}` | `inputs`, `results`, `devices`, `racks`, `capacity`, `warnings`, `calculations` |
